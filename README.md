#### SceneView

[**sceneview/sceneview**](https://github.com/sceneview/sceneview) is the open-source 3D & AR SDK I created for Jetpack Compose, SwiftUI and the web, with Flutter and React Native bridges. It is built on Filament and ARCore on Android and on RealityKit on Apple platforms. It gets about 2M downloads a year on Maven Central, from 1,100+ companies. It is also written for AI assistants, with an MCP server, `AGENTS.md` and `llms.txt`.

→ [Docs & live demos](https://sceneview.github.io)
